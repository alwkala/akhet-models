**الإصدار:** 0.1.0 (مسودة توثيقية مرجعية)  
**التاريخ:** 23 أكتوبر 2026  
**النموذج الأساسي:** Qwen3.5 Base

## 1. نبذة عن النموذج

**آخت-رع 1 (Akhet-Ra1)** هو نموذج ذكاء اصطناعي محلي تطوره **Alwkala Digital Labs** من خلال إجراء الضبط الدقيق (Fine-tuning) على النموذج الأساسي **Qwen3.5 Base**.

يهدف النموذج إلى توفير طبقة الذكاء (**رع / Ra**) داخل منظومة **AkhetRa**، لدعم تطبيقات الذكاء الاصطناعي المحلية وسير العمل القائم على الوكلاء الذكيين (Agents) الخاضعين لحوكمة أمنية دقيقة.

ينطلق المشروع من رؤية عملية:
1. تقريب قدرات الذكاء الاصطناعي من المستخدم وبياناته الشخصية أو المؤسسية.
2. السيادة الكاملة على بيئة التشغيل والاستدلال التام دون الحاجة للاتصال بالسحابة.
3. التوافق العالي مع متطلبات اللغة العربية، واستدعاء الأدوات، ومعالجة النصوص المنظمة البرمجية.

## 3. فلسفة التصميم

يعتمد تصميم آخت-رع 1 على خمسة مبادئ هندسية صارمة:

1. **الأولوية للتشغيل المحلي (Local-first):** إبقاء المعالجة والبيانات محلياً على جهاز المستخدم لمنع تسرب البيانات الحساسة.
2. **الاهتمام اللغوي العربي (Arabic-aware):** استيعاب أوزان وتراكيب الفصحى، والمصطلحات التقنية المعربة، واللهجات الحية (خاصة المصرية)، والتبديل اللغوي (Code-switching).
3. **الجاهزية للتكامل (Integration-ready):** التوافق المباشر مع واجهات البرمجة، والوكلاء التلقائيين، وأطر استدعاء الأدوات الخارجية (Tool Calling).
4. **التوافق مع الحوكمة (Governance-compatible):** تصميم النموذج ليعمل داخل بيئات تشغيل تفرض قيود الصلاحيات ومراجعة العمليات.
5. **الاستقلال المعماري (Model Independence):** عدم احتكار بيئة التشغيل؛ حيث تسمح منظومة AkhetRa بتبديل النموذج الأساسي بنماذج أخرى حسب السياسة المتبعة.

## 4. معمارية منظومة AkhetRa

تنقسم المنظومة إلى شقين متكاملين:

* **RA (رع - طبقة الذكاء):**
  النموذج اللغوي المسؤول عن توليد النصوص، والتفكير الاستدلالي، واقتراح استدعاء الأدوات وصياغة معاملاتها.
* **AKHET (آخت - طبقة التشغيل والحوكمة):**
  المنصة والبيئة المسؤولة عن إدارة الذاكرة، ميزانية السياق، جدار الحماية (Firewall)، صلاحيات الملفات، الموافقة البشرية، وتتبع سجلات التدقيق (Audit Logs).

> **القاعدة الذهبية:** *رع يفكر ويقترح، وآخت تحكم وتنفذ.*  
> لا يملك النموذج صلاحية التنفيذ المباشر للأوامر التدميرية أو العمليات الحساسة إلا بعد مصادقة طبقة الحوكمة في بيئة التشغيل.

## 5. الاستخدامات المستهدفة وحدود الاستخدام

### 5.1 الاستخدامات المستهدفة (تخضع للتقييم المستمر)
- المساعدات الذكية المحلية للشركات والأفراد.
- استرجاع المعرفة المحلية والبحث في المستندات (RAG) دون تسريب البيانات خارج الشبكة.
- المساعدة في تطوير البرمجيات، قراءة وفحص الأكواد، وتصحيح الأخطاء.
- معالجة البيانات المنظمة وتوليد مخرجات بتنسيق JSON متوافقة مع المخططات (Schemas).
- تنفيذ المهام التكرارية المنسقة عبر وكلاء ذكيين خارجيين.

### 5.2 الاستخدامات المحظورة وخارج النطاق
- اتخاذ قرارات مصيرية في المجالات الطبية، القانونية، أو المالية دون إشراف بشري مختص.
- منح النموذج صلاحية تنفيذ الأوامر على نظام التشغيل دون رقابة أو موافقة مسبقة.
- انتهاك رخصة النموذج الأساسي أو السياسات التنظيمية المحلية.
- الاعتماد على مخرجات النموذج كحقائق مطلقة دون تدقيق نظراً لاحتمالية حدوث هلوسة (Hallucination).

## 6. التشغيل السريع والأدوات المرفقة

يحتوي المستودع على أدوات تنفيذ سريعة مبرمجة لبيئة PowerShell ومحرك `llama.cpp`:

### 6.1 التشغيل التفاعلي عبر لوحة التحكم (TUI Dashboard)
يوفر السكربت `run-Ra-tui.ps1` واجهة تفاعلية حية تعرض:
- حالة كارت الشاشة (GPU)، استهلاك الذاكرة (VRAM)، والحرارة.
- معدل توليد التوكنز في الثانية (Tokens/sec).
- سجل الأحداث (Logs) مع إمكانية التصفية، وأزرار التحكم السريع (إعادة التشغيل، نسخ الرابط، الإيقاف النظيف).

```powershell
.\run-Ra-tui.ps1 -Port 8080 -ContextSize 32768
```

### 6.2 التشغيل كخدمة خلفية (Headless Service)
عبر السكربت `run-Ra-0.ps1`:
```powershell
.\run-Ra-0.ps1
```

### 6.3 التشغيل المباشر من منصة Hugging Face (بدون تحميل مسبق)
بفضل تكامل مستودع Hugging Face وصيغة GGUF، يمكنك تشغيل أو استضافة **Akhet-Ra1** مباشرة بأمر واحد:

#### التشغيل الفوري في الطرفية (`llama-cli`):
```bash
llama-cli -hf alwkala/Akhet-Ra1:Ra-1-4B-Q4_K_M.gguf -p "أنت مساعد ذكي محلي خاضع لمنظومة آخت-رع." -cnv
```

#### الاستضافة كخادم متوافق مع OpenAI (`llama-server`):
```bash
llama-server --hf-repo alwkala/Akhet-Ra1 --hf-file Ra-1-4B-Q4_K_M.gguf --alias "Akhet-Ra-1" -c 32768 -ngl 99 --host 0.0.0.0 --port 8080
```

#### التشغيل الفوري عبر Ollama:
```bash
ollama run hf.co/alwkala/Akhet-Ra1:Ra-1-4B-Q4_K_M.gguf
```

### 6.4 أمر التشغيل المحلي لمحرك llama-server
```powershell
llama-server.exe `
  -m "A:\.lmstudio\Akhet\Ra-1\Ra-1-4B-Q4_K_M.gguf" `
  --alias Akhet-Ra-1 `
  -ngl 99 `
  -c 32768 `
  -t 8 `
  --jinja `
  --flash-attn on `
  -ctk q4_0 `
  -ctv q4_0 `
  --batch-size 1024 `
  --ubatch-size 512 `
  --host 0.0.0.0 `
  --port 8080
```

## 7. إعدادات التوليد الموصى بها (Sampling Parameters)

| المعامل | القيمة الموصى بها | الوظيفة |
| :--- | :--- | :--- |
| **درجة الحرارة (Temperature)** | `0.6` إلى `0.7` | توازن دقيق بين الإبداع والالتزام المنطقي |
| **Top-P** | `0.90` | حصر احتمالات الكلمات بنسبة 90% |
| **Top-K** | `40` | تقليل التشويش في مخرجات الكلمات |
| **عقوبة التكرار (Repetition Penalty)** | `1.10` | منع تكرار العبارات في الجمل الطويلة |
| **طول السياق (Context Size)** | `32,768` (32K) | استيعاب وثائق ومحادثات ومطالبات طويلة |
| **تكميم كاش الذاكرة (KV Cache)** | `q4_0` | توفير 50% من استهلاك ذاكرة الكارت مما يتيح تشغيل سياق 32K في 6GB VRAM |
