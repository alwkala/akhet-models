| Version | Supported          |

| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

The **Alwkala Digital Labs** team takes the security and safety of our AI models, governance runtimes, and local tools seriously.

If you discover a security vulnerability or prompt injection bypass:

1. **Do not create a public issue.**
2. Send an email to **security@alwkala.com** with details:
   - Description of the vulnerability.
   - Affected model or script version.
   - Minimal reproduction prompt or payload.
   - Any proposed remediation.
3. We will acknowledge receipt within 48 hours and work with you on a responsible disclosure timeline.
