# Akhet-Ra1 — Interactive Spaces Demo

Interactive demo and evaluation interface for **Akhet-Ra1**, an Arabic-aware, local-first language model developed by **Alwkala Digital Labs**.

- **Model Repository:** [alwkala/Akhet-Ra1](https://huggingface.co/alwkala/Akhet-Ra1)
- **Base Architecture:** Qwen3.5 4B Hybrid SSM + Self-Attention
- **Quantization:** GGUF Q4_K_M (2.52 GB)
- **Developer:** [Alwkala Digital Labs](https://alwkala.com)
